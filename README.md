# C 2D Array Matrix

A beginner-friendly C program demonstrating the use of a two-dimensional array in C and displaying its elements in matrix form.

## Concepts Used

- 2D Arrays
- Rows and Columns
- Array Indexing
- Nested `for` Loops
- Matrix Form
- Field Width Specifier `%4d`

## Array Used

The program uses a 2D array with:

- 3 Rows
- 4 Columns
- Total 12 Elements

## Sample Output

```text
-------IN MATRIX FORM-------

  92  95  95  65
  74  78  85  55
  23  34  56  78
